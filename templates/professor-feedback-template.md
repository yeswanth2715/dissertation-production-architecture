# Professor Feedback Template

Use this structure when converting professor feedback into a reusable review artifact.

```text
# Professor Feedback

Topic:
Student:
Date received:
Source format:

## Summary

## Required Changes

## Suggested Improvements

## Questions To Clarify

## Affected Knowledge-Base Files

## Affected Outputs

## Acceptance Checklist

## Response Plan
```

Output formats:

```text
professor-feedback.md
professor-feedback.docx
```
