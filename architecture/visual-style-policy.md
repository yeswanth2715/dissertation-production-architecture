# Academic Thesis Visual Style Policy

Use this policy for thesis figures, diagrams, conceptual frameworks, workflow models, survey charts, methodology visuals, and dashboard-style figures.

## Scope

This policy controls the visual identity of figures. It does not override the source-based image rule in `architecture/originality-policy.md`.

Evidence figures must be source-backed or data-derived. Generated visuals may be used for diagrams, frameworks, and abstract process figures only when they do not pretend to be empirical evidence.

## Overall Aesthetic

```text
- publication-quality academic research figure
- sophisticated MSc/PhD dissertation aesthetic
- modern but academically conservative
- clean European research-report design
- minimal, precise, and technical
- flat vector graphics where possible
- white or very light neutral background
- generous negative space
- strong visual hierarchy
- no stock-image, corporate marketing, or social-media aesthetic
```

## Colour Palette

```text
Primary:        #183B56  deep academic navy
Secondary:      #486581  muted blue-grey
Accent:         #2F80ED  restrained research blue
Highlight:      #56B4A9  muted teal
Light fill:     #EAF2F8  very pale blue
Neutral fill:   #F4F6F8  cool light grey
Main text:      #1F2933  charcoal
Secondary text: #52606D  slate grey
Borders:        #BCCCDC  subtle grey-blue
Background:     #FFFFFF
```

Colour usage:

```text
- 70-80% white or neutral space
- 15-20% navy, grey, and pale blue
- maximum 5-10% accent colour
- colour must communicate hierarchy, grouping, emphasis, or categories
- never use colour only as decoration
- charts must remain understandable in grayscale where possible
```

## Prohibited Visual Patterns

Do not use:

```text
- bright saturated colours
- rainbow palettes
- neon blue or purple
- AI-style purple gradients
- glowing effects
- glassmorphism
- 3D objects
- metallic surfaces
- shadows behind every object
- glossy buttons
- cartoon illustrations
- isometric corporate graphics
- photorealistic people
- generic stock imagery
- futuristic AI imagery
- glowing brains
- robots
- excessive icons
- decorative blobs or floating ornaments
```

## Shape And Layout Rules

```text
- use simple rectangles and subtly rounded rectangles
- use thin 1-1.5 pt borders
- keep geometry consistent within each figure
- avoid floating 3D cards
- keep diagrams readable at DOCX page width
- normally use 4-7 major blocks per conceptual diagram
- leave enough spacing for captions and source notes
```

## Lines And Arrows

```text
- use thin, precise lines
- use dark grey, muted navy, or blue-grey strokes
- keep stroke width consistent
- use understated arrowheads
- do not use glowing connectors
```

## Typography

```text
- use a modern academic sans-serif appearance such as Arial, Helvetica, Inter, or Source Sans
- use charcoal rather than pure black where appropriate
- use restrained bold for hierarchy
- keep labels short and academic
- do not use decorative typography
```

## Depth

Figures should be mostly flat. If separation is required, use only extremely subtle shadows. Do not use dramatic depth, perspective, or 3D effects.

## Caption And Source Rules

Every figure must include:

```text
- chapter-correct figure numbering
- a concise academic caption
- source note when adapted from, reproduced from, or based on external material
- survey/data source note when generated from project data
```

Professor-facing figures must not include internal architecture language such as project numbers, `/learn`, QA notes, tool/model decisions, pre-survey status, or staged workflow instructions.

## Final Appearance Standard

The finished figure should look professionally designed for a peer-reviewed academic publication, doctoral dissertation, or high-quality scientific research report. It should not look like marketing material, a startup pitch deck, social media content, or a generic AI-generated illustration.
